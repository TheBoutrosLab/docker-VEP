# docker-VEP

Dockerfile for the [Ensembl Variant Effect Predictor (VEP)](https://www.ensembl.org/info/docs/tools/vep/index.html), which predicts the effects of genomic variants on genes, transcripts, and proteins.

## Version

| Tool | Version |
|------|---------|
| VEP | 116.2 |
